# Telvax documentation in Brazilian Portuguese

Translation of the documentation in [telvax/telvax](https://github.com/telvax/telvax).

## Scope

* `docs/guide/tour.md` first, then `docs/guide/use-cases.md`, then `README.md`.
* Code, command names, keywords and error messages stay in English. Translate the text around them.
* Each translated file starts with the commit of `telvax/telvax` it was translated from, so a reader can see what changed since.
